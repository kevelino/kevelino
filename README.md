
I build products end-to-end — from backend to mobile, from idea to production.
Obsessed with shipping fast and building useful software for African businesses:
payments, ticketing, property management, and the everyday tools they run on.

## 🔨 Currently building

- **Locatix** — rental management platform for landlords in Cameroon (rent collection via Mobile Money, receipts, arrears tracking, caretaker access)
- **Transport suite** — ticketing + parcel/mail management for a bus company, with thermal receipt printing in agencies
- **Mobile Money aggregation API** — one gateway between apps and MTN / Orange payment APIs

## 🚀 Projects

### 🏠 Locatix *(in development)*
Rental management SaaS for landlords — Next.js · Django  
Rent collection via MTN MoMo / Orange Money, automatic receipts, arrears reminders, caretaker roles, multi-landlord isolation

### 🎫 ETResS / DISCOM
Bus ticketing & reservation platform — Django + Next.js  
Mobile payments (MTN MoMo · Orange Money), PDF ticket generation, Celery/Redis task queues, VPS deployment

### 🚌 Transport ticketing & parcel management
Operations software for a transport company — Django · React  
Agency ticketing (POS), parcel & mail tracking, ESC/POS thermal receipt printing, role-based agency access

### 🧾 Faktum
B2B invoicing SaaS for Cameroonian law firms and SMEs

### 🔧 Fundi
On-demand technician marketplace — Flutter · FastAPI

### 📋 Earlist
Product validation & waitlist management SaaS — Next.js 14 · Supabase · Stripe · Resend  
AI-generated reports via Gemini 3 Pro· Live in production

### 🔒 DeepBlock
Android focus & productivity app — React Native · Expo · TypeScript  
Animated timer, notification blocking, ambient sounds, native Kotlin home screen widget
